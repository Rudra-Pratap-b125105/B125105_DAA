DAA LAB–6
Q2. 0/1 KNAPSACK USING DYNAMIC PROGRAMMING — MAXIMUM PROFIT ONLY

AIM
Given n items, their weights and profits, and knapsack capacity W, find the maximum
profit when each item can be selected at most once.

PSEUDOCODE
KNAPSACK(n, W, weight, profit)
    create dp[0..n][0..W]

    for i = 0 to n
        for w = 0 to W
            if i == 0 OR w == 0
                dp[i][w] = 0
            else if weight[i-1] <= w
                include = profit[i-1] + dp[i-1][w-weight[i-1]]
                exclude = dp[i-1][w]
                dp[i][w] = max(include, exclude)
            else
                dp[i][w] = dp[i-1][w]

    return dp[n][W]


SAMPLE INPUT
4
2 3 4 5
3 4 5 6
5

SAMPLE OUTPUT
Maximum Profit = 7

TIME COMPLEXITY — HOW IT IS CALCULATED
The DP table has (n+1)(W+1) cells.

The outer loop runs n+1 times = O(n).
For every item, the inner loop runs W+1 times = O(W).

Therefore:
T(n,W) = (n+1)(W+1) * O(1)
       = O(nW)

Each cell performs only constant-time operations: comparison, addition and assignment.

Therefore, TIME COMPLEXITY = O(nW).

SPACE COMPLEXITY
The table contains (n+1)(W+1) entries.
S(n,W) = O(nW).

NOTE
0/1 means an item is either taken once or not taken. It cannot be split and cannot be reused.
