DAA LAB 8 - QUESTION 4
LONGEST INCREASING SUBSEQUENCE (LIS)
Documentation (Code Excluded)

1. PROBLEM STATEMENT
Given an integer array A[0..n-1], find the length of the longest strictly increasing subsequence.

For a strictly increasing subsequence:
A[j] < A[i] whenever j occurs before i in the subsequence.

The implementation also reconstructs one valid LIS for verification.

2. APPROACH
Dynamic Programming is used.

Let:
dp[i] = length of the longest strictly increasing subsequence ending at A[i].

Initially:
dp[i] = 1

For every previous position j < i:
If A[j] < A[i], then A[i] can extend the subsequence ending at j.

Therefore:
dp[i] = max(dp[i], dp[j] + 1)

A parent[] array stores the previous index selected for each position.

3. RECONSTRUCTION
Maintain:
maxLength = largest dp[i]
lastIndex = index where this maximum occurs.

Starting at lastIndex, repeatedly follow parent[] backwards. Store the elements in reverse order and then print them in forward order.

4. SAMPLE INPUT
Number of elements: 8
Array:
10 22 9 33 21 50 41 60

5. SAMPLE OUTPUT
LIS Length: 5
One LIS:
10 22 33 50 60

6. PSEUDOCODE

LIS(A, n)

    if n <= 0
        return 0

    for i = 0 to n-1
        dp[i] = 1
        parent[i] = -1

    maxLength = 1
    lastIndex = 0

    for i = 1 to n-1
        for j = 0 to i-1

            if A[j] < A[i] and dp[j] + 1 > dp[i]
                dp[i] = dp[j] + 1
                parent[i] = j

        if dp[i] > maxLength
            maxLength = dp[i]
            lastIndex = i

    reconstruct using parent[]

    return maxLength

7. TIME COMPLEXITY
For i = 1 to n-1, the inner loop checks j = 0 to i-1.

Number of comparisons:
1 + 2 + 3 + ... + (n-1)

= n(n-1)/2

Therefore:
T(DP) = Theta(n^2)

Reconstruction takes O(n) in the worst case.

Overall:
Theta(n^2)

8. SPACE COMPLEXITY
dp[] = O(n)
parent[] = O(n)
reconstructed LIS = O(n)

Therefore:
O(n) auxiliary space.

9. IMPORTANT POINTS
- Strictly increasing means use A[j] < A[i], not A[j] <= A[i].
- The program returns one LIS; multiple LISs of the same maximum length may exist.
- This is the standard O(n^2) dynamic-programming solution.
