DAA LAB 8 - QUESTION 5
MAXIMUM SUM INCREASING SUBSEQUENCE (MSIS)
Documentation (Code Excluded)

1. PROBLEM STATEMENT
Given an array of positive integers, find the maximum possible sum of a strictly increasing subsequence.

The implementation also reconstructs one maximum-sum increasing subsequence.

2. APPROACH
Dynamic Programming is used.

Let:
dp[i] = maximum sum of a strictly increasing subsequence ending at A[i].

Initially:
dp[i] = A[i]

For every j < i:
If A[j] < A[i], then A[i] can be appended to the increasing subsequence ending at A[j].

Therefore:
dp[i] = max(dp[i], dp[j] + A[i])

A parent[] array is maintained to reconstruct the selected subsequence.

3. SAMPLE
Array:
1 101 2 3 100 4 5

One maximum-sum increasing subsequence is:
1 2 3 100

Sum:
1 + 2 + 3 + 100 = 106

Therefore:
Maximum Sum = 106

4. SAMPLE INPUT
Number of elements: 7
Array:
1 101 2 3 100 4 5

5. SAMPLE OUTPUT
Maximum Sum: 106
Maximum Sum Increasing Subsequence:
1 2 3 100

6. PSEUDOCODE

MAXIMUM-SUM-IS(A, n)

    if n <= 0
        return

    for i = 0 to n-1
        dp[i] = A[i]
        parent[i] = -1

    maxSum = A[0]
    lastIndex = 0

    for i = 1 to n-1
        for j = 0 to i-1

            if A[j] < A[i]
                if dp[j] + A[i] > dp[i]
                    dp[i] = dp[j] + A[i]
                    parent[i] = j

        if dp[i] > maxSum
            maxSum = dp[i]
            lastIndex = i

    reconstruct sequence using parent[]

    return maxSum

7. TIME COMPLEXITY
The nested loops perform:

1 + 2 + 3 + ... + (n-1)

comparisons.

This equals:
n(n-1)/2

Therefore:
T(DP) = Theta(n^2)

Reconstruction takes O(n).

Overall:
Theta(n^2)

8. SPACE COMPLEXITY
dp[] = O(n)
parent[] = O(n)
reconstructed sequence = O(n)

Therefore:
O(n) auxiliary space.

9. IMPORTANT DIFFERENCE FROM LIS
LIS maximizes the number of elements.

MSIS maximizes the sum of elements.

For LIS:
dp[i] represents a length.

For MSIS:
dp[i] represents a sum.

Therefore MSIS starts with:
dp[i] = A[i]

rather than:
dp[i] = 1
