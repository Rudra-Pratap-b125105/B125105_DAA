DAA LAB 8 - QUESTION 3
LONGEST COMMON SUBSEQUENCE (LCS)
Documentation (Code Excluded)

1. PROBLEM STATEMENT
Given two sequences X and Y, find the length of their Longest Common Subsequence (LCS) and reconstruct one actual LCS.

A subsequence does not need to occupy consecutive positions, but the relative order of its elements must be preserved.

2. APPROACH
Dynamic Programming is used.

Let:
dp[i][j] = length of the LCS of the first i characters of X and the first j characters of Y.

Base cases:
dp[i][0] = 0
dp[0][j] = 0

If X[i-1] == Y[j-1]:
    dp[i][j] = dp[i-1][j-1] + 1

Otherwise:
    dp[i][j] = max(dp[i-1][j], dp[i][j-1])

3. RECONSTRUCTION
Start from dp[m][n].

If X[i-1] == Y[j-1], that character belongs to an LCS:
- store it
- move diagonally to (i-1,j-1)

Otherwise:
- move toward the neighboring cell with the larger DP value.

Continue until i = 0 or j = 0.

The collected characters are in reverse order, so they are reversed before printing.

If both neighboring values are equal, either direction can produce a valid LCS.

4. SAMPLE INPUT
First sequence: ABCBDAB
Second sequence: BDCABA

5. SAMPLE OUTPUT
LCS Length: 4
One possible LCS: BCBA

Other valid LCSs of the same length may also exist.

6. PSEUDOCODE

LCS(X, Y, m, n)

    for i = 0 to m
        dp[i][0] = 0

    for j = 0 to n
        dp[0][j] = 0

    for i = 1 to m
        for j = 1 to n

            if X[i-1] == Y[j-1]
                dp[i][j] = dp[i-1][j-1] + 1
            else
                dp[i][j] = max(dp[i-1][j],
                                dp[i][j-1])

    return dp[m][n]

RECONSTRUCT-LCS(X, Y, dp, m, n)

    i = m
    j = n
    index = dp[m][n]

    while i > 0 and j > 0

        if X[i-1] == Y[j-1]
            LCS[index-1] = X[i-1]
            i--
            j--
            index--
        else if dp[i-1][j] > dp[i][j-1]
            i--
        else
            j--

    print LCS

7. TIME COMPLEXITY
There are (m+1)(n+1) DP cells.

Each cell takes constant time to calculate.

Therefore:
T(DP) = Theta(mn)

Traceback visits at most m+n cells:
T(traceback) = O(m+n)

Overall:
Theta(mn) + O(m+n) = Theta(mn)

8. SPACE COMPLEXITY
The DP table requires O(mn).
The reconstructed LCS requires O(min(m,n)) in a standard compact representation.
Input strings require O(m+n).

Dominant space:
O(mn)

9. IMPORTANT POINTS
- Subsequence does not mean contiguous.
- A different valid LCS may be obtained when DP values are tied.
- The DP table gives both the length and the information needed for reconstruction.
