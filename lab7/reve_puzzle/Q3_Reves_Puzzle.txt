QUESTION 3 — REVE'S PUZZLE

Problem
There are four pegs and n disks of different sizes. Initially all disks are on one
peg in decreasing size order. Move all disks to another peg without placing a larger
disk on a smaller disk. Find an algorithm giving 33 moves for n = 8 and generalize it.

Method — Frame-Stewart dynamic programming
Choose k smaller disks to be handled using the four-peg problem.

1. Move the top k disks to an auxiliary peg using four pegs:
       T(k) moves.
2. Move the remaining n-k disks using only three pegs:
       2^(n-k) - 1 moves.
3. Move the k disks from the auxiliary peg to the destination using four pegs:
       T(k) moves.

Thus:
    T(n) = min over k=1..n-1
           [2T(k) + 2^(n-k) - 1]

Base cases:
    T(0) = 0
    T(1) = 1

We store the value of k that gives the minimum in split[n], so that an actual
sequence of moves can be reconstructed.

For n = 8
The optimal split is k = 4 under the standard Frame-Stewart recurrence:

    T(4) = 9
    T(8) = 2T(4) + 2^4 - 1
         = 2(9) + 16 - 1
         = 33

Therefore the eight-disk puzzle can be solved in 33 moves.

Final algorithm
1. Set T[0]=0 and T[1]=1.
2. For n = 2..N:
       initialize T[n] to infinity.
       try every k = 1..n-1.
       cost = 2*T[k] + 2^(n-k) - 1.
       keep the minimum and remember k.
3. Output T[N] and the best split.

Pseudocode
REVE(N):
    T[0] = 0
    T[1] = 1
    for d = 2..N:
        T[d] = infinity
        for k = 1..d-1:
            cost = 2*T[k] + 2^(d-k) - 1
            if cost < T[d]:
                T[d] = cost
                split[d] = k
    return T[N]

Complexity
There are N DP states and state d examines d-1 split points:

    T(N) = sum(d=2..N) O(d)
         = O(N^2)

Computing powers by repeated multiplication gives O(N) total if each power is
recomputed naively inside the loops; alternatively precompute powers of two in O(N),
after which the DP remains O(N^2).

Space:
    DP array T[0..N] and split[0..N]:
    O(N)
