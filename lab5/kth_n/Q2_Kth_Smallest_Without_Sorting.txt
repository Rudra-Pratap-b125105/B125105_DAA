DAA LAB-5
QUESTION 2: FIND THE K-TH SMALLEST ELEMENT WITHOUT SORTING

PROBLEM STATEMENT
Given a list of N numbers, find the K-th smallest element without sorting the list. Analyze the complexity of the algorithm.

APPROACH
Use Quickselect. It is a modified Quick Sort selection algorithm. After partitioning, only the side containing the required K-th position is processed further.

Since array indexing starts from zero:
K-th smallest element -> zero-based index K - 1.

ALGORITHM
1. Read N elements and K.
2. Check that 1 <= K <= N.
3. Convert K to zero-based index: k = K - 1.
4. Partition the array around a pivot.
5. If the pivot position equals k, return the pivot.
6. If k is smaller, continue on the left partition.
7. Otherwise, continue on the right partition.
8. Display the result.

PSEUDOCODE
QUICKSELECT(A, low, high, k)
    while low <= high
        pivotIndex <- PARTITION(A, low, high)

        if pivotIndex = k
            return A[pivotIndex]
        else if k < pivotIndex
            high <- pivotIndex - 1
        else
            low <- pivotIndex + 1

PARTITION(A, low, high)
    pivot <- A[high]
    i <- low - 1

    for j <- low to high - 1
        if A[j] <= pivot
            i <- i + 1
            swap A[i] and A[j]

    swap A[i + 1] and A[high]
    return i + 1

FIND_KTH_SMALLEST(A, N, K)
    if K < 1 OR K > N
        print "Invalid K"
        return

    index <- K - 1
    result <- QUICKSELECT(A, 0, N-1, index)
    print result

WORKING
Example:
N = 8
Elements = 12 3 5 7 4 19 26 8
K = 4

Required zero-based index:
K - 1 = 3

Quickselect partitions the array and checks the pivot's position. It continues only in the partition containing index 3.

The 4th smallest element is:
7

The entire array does not have to be sorted.

TIME COMPLEXITY
Partition takes O(N).

Best case:
If the pivot reaches the required position immediately:
O(N)

Average case:
T(N) = T(N/2) + O(N)
     = N + N/2 + N/4 + ...
     = O(N)

Therefore average-case complexity = O(N).

Worst case:
T(N) = T(N-1) + O(N)
     = N + (N-1) + ... + 1
     = N(N+1)/2
     = O(N^2)

SPACE COMPLEXITY
The partitioning is performed in-place:
O(1) auxiliary space.

COMPLEXITY SUMMARY
Best case: O(N)
Average case: O(N)
Worst case: O(N^2)
Auxiliary space: O(1)

SAMPLE OUTPUT

IMPORTANT VIVA POINTS
1. Why is the index K - 1?
   Because array indexing begins at zero.

2. How is Quickselect different from Quick Sort?
   Quick Sort recursively processes both partitions; Quickselect processes only the partition containing the required element.

3. Does the array need to be sorted?
   No.

4. Average complexity?
   O(N).

5. Worst-case complexity?
   O(N^2).
